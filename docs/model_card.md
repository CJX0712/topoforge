# TopoForge 模型卡（Model Card）

> 系统：TopoForge · 版本：v0.1.0 · 作者：晨星 · 任务域：持久同调拓扑数据分析（TDA）

## 1. 模型细节

- **类型**：可解释的拓扑特征工程引擎（非端到端黑箱模型）。
- **核心算法**：Vietoris–Rips 复形 + 标准约简（Edelsbrunner, GF(2)）持久同调。
- **输出**：Betti 数 (β₀,β₁,β₂)、持久同调图、固定 18 维拓扑特征向量。
- **下游分类器**：Tier-0 sklearn RandomForest；Tier-1 纯 numpy 最近质心（离线兜底）。
- **确定性**：`set_all(seed)` + 固定子种子派生，二次运行逐位可复现。

## 2. 预期用途

- 从点云恢复/量化**拓扑不变量**（连通分支、孔洞、空腔数）。
- 为几何/科学数据提供**几何盲的拓扑特征**，与欧氏特征互补。
- 教学与可复现研究：手建复形 + 采样流形的解析 Betti 不变量自测。

## 3. 诚实性能声明（不夸大）

| 指标 | 结论 | 说明 |
|---|---|---|
| **引擎正确性** | 解析 Betti 恢复命中率 ≈ 0.84（整体，5 seed×6/shape） | 非-torus 形状更高；torus H₂ 为 VR 已知限制 |
| **分类效用** | 拓扑特征 acc 显著低于欧氏几何特征（典型 0.80 vs 1.00） | **TDA 已知性质**：持久是粗同伦不变量，几何丰富任务上不敌欧氏 |
| **确定性** | 核心指标 mean±std 二次运行逐位一致 | DoD 硬门槛 |

> **关键诚实声明**：本引擎的本职性能目标是**恢复已知拓扑结构**（引擎正确性），
> 而非在几何丰富分类任务上超越欧氏特征。任何宣称"拓扑特征全面超越几何特征"的说法
> 都与 TDA 的数学性质相悖，本卡不予支持。

## 4. 训练 / 采样数据

- 合成流形生成器：`circle / eight / line / sphere / torus / blob`，固定 seed 可复现。
- 无外部训练数据；分类基准为合成数据上的小样本对照实验。

## 5. 局限性

- 点云规模：标准约简为 O(n³) 量级，万级点云需近似/稀疏化（本版未含）。
- 采样密度：稀疏采样下高维 Betti（如 torus H₂）难以由有限持续条恢复。
- 度量：仅支持欧氏 VR 复形；其他度量（测地、核）待扩展。

## 6. 伦理与风险

- 纯几何工具，无偏见性风险；输出为数学不变量，可解释。
- 依赖项（numpy/scipy/sklearn）均为成熟开源库，无隐私数据外泄。

## 7. 复现

```bash
python examples/run_demo.py      # 落盘 benchmark.json（含三部分：recovery / classification / determinism）
python -m pytest -q              # 不变量 + 确定性 + 离线兜底测试
```
